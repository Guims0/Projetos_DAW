# Projetos DAW - Exercícios em PHP 💻

Este repositório foi criado para armazenar e organizar todos os exercícios práticos e trabalhos desenvolvidos nas aulas da disciplina **DAW**.

## 🗂️ Lista de Exercícios

Abaixo está a lista dos exercícios disponíveis neste repositório. Cada atividade está separada em sua própria pasta:

* **[Exercício 01: Calculadora Básica](https://github.com/Guims0/Projetos_DAW/tree/main/Exercicios/Calculadora)** 
  * Uma calculadora simples que realiza as quatro operações matemáticas básicas (adição, subtração, multiplicação e divisão) recebendo os dados do usuário via formulário HTML (`$_GET`).
 
* **[Exercício 02: Cadastro de Aluno em TXT](https://github.com/Guims0/Projetos_DAW/tree/main/Exercicios/ArquivoAluno)** 
  * Um sistema simples composto por um formulário HTML que recebe os dados de um aluno (Nome, Matrícula e Curso) via método `POST` e utiliza PHP para gravar e armazenar essas informações de forma   permanente em um arquivo de texto (`alunos.txt`).
    
*(Novos exercícios serão listados aqui conforme forem solicitados pelo professor).*

## 🚀 Como Executar os Projetos Localmente

Para rodar e testar os códigos na sua máquina, siga os passos abaixo:

1. É necessário ter um servidor local com suporte a PHP instalado (recomendamos o [XAMPP](https://www.apachefriends.org/pt_br/index.html)).
2. Faça o clone deste repositório ou baixe os arquivos.
3. Coloque a pasta `Projetos_DAW` dentro do diretório `htdocs` do seu servidor (geralmente localizado em `C:\xampp\htdocs\`).
4. Abra o painel de controle do XAMPP e inicie o serviço **Apache**.
5. Abra o seu navegador e acesse o endereço correspondente à pasta do exercício. Exemplo:
   `http://localhost/Projetos_DAW/nome_da_pasta_do_exercicio/index.html`
